# 🏥 Medical Symptom Checker

A rule-based AI expert system that analyzes symptoms and suggests possible medical conditions with a detailed PDF report.

![Python](https://img.shields.io/badge/Python-3.11+-blue?logo=python)
![CustomTkinter](https://img.shields.io/badge/GUI-CustomTkinter-green)
![SQLite](https://img.shields.io/badge/Database-SQLite-orange)

---

## ✨ Features

- 🔍 Analyze symptoms using weighted scoring logic
- 🧠 Rule-based expert system covering 15 diseases and 47 symptoms
- 📄 Export detailed PDF diagnosis report
- 🗄️ SQLite database to store diagnosis history
- 📋 View last 20 diagnoses
- 🌙 Dark modern UI

---

## 🛠️ Tech Stack

- Python 3.11+
- CustomTkinter (GUI)
- SQLite (Database)
- ReportLab (PDF Generation)

---

## 🚀 Installation

1. Clone the repository:
```bash
git clone https://github.com/Arhamali654/medical-symptom-checker.git
cd medical-symptom-checker
```

2. Install dependencies:
```bash
pip install customtkinter reportlab
```

3. Run the app:
```bash
python symptom_checker.py
```
